# Mridul Sharma — Business Analytics Portfolio

A responsive personal portfolio website built with HTML and CSS.

## Website
After GitHub Pages is enabled:
https://cynotryl07.github.io/Mridul-Sharma-Business-Analytics-Portfolio/

## Enable GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/ (root)**, then Save.
4. Wait for the deployment to finish.

## Personalise before sharing
- Replace `ADD_YOUR_EMAIL` in `index.html` with your preferred email address.
- Replace `ADD_LINKEDIN_URL` with your LinkedIn profile URL.
- Add project reports, datasets, dashboards and screenshots as you complete them.
- Keep the skills section aligned with your actual proficiency.

## Portfolio integrity
Project cards describe academic work and practice areas based on information shared by the owner. Add supporting files and outcomes before presenting them as completed case studies. SQL, Python, Power BI and Tableau are listed as learning goals, not professional proficiency.
